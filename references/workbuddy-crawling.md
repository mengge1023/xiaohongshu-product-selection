# 腾讯 WorkBuddy 自动取证

## 能力发现

目标环境是腾讯 WorkBuddy。开始时检查当前会话已安装、启用并授权的能力，优先级如下：

1. 对应平台的专用连接器、MCP 或 Skill；
2. WorkBuddy 专用浏览器或可读取登录态页面的浏览器工具；
3. 通用网页读取/抓取工具；
4. 以上均不可用时，才请用户补充当前缺失数据。

不要假定固定工具名、接口名或参数。调用前读取运行时暴露的工具说明。只使用只读能力，不执行下单、收藏、发布、关注、评论、私信或修改账号信息。

## 小红书商品页

用户发商品链接后自动打开并提取：

- 规范化商品 URL、商品名和可见规格；
- 当前销售价格；
- 累计销量；
- 24 小时加购；
- 页面抓取时间。

字段必须对应当前商品和当前规格。若页面以区间、约数、图片文字或动态组件展示，优先继续读取页面结构/OCR；仍无法确认准确值时将字段标记为 `unverified`，不要按约数评分。

## 小红书笔记与对标搜索

用户发笔记链接时先读取笔记详情和关联商品。若存在可访问的关联商品链接，进入商品判断；否则请用户补充商品链接。

对商品进行对标取证时，使用当前已授权的小红书搜索能力搜索同款带货笔记：

1. 用商品名、核心型号/规格和可识别的同款特征搜索；
2. 只保留能够核实为同一商品的笔记；相似品不得标记为同款；
3. 对每条候选笔记分别读取笔记 URL、作者粉丝数、发布时间、点赞数、关联商品及抓取时间；
4. 将发布时间换算成 `days_ago` 时保留原始发布时间；
5. 优先覆盖最近 30 天，并允许检查至 90 天；
6. 每条笔记作为独立证据对象，禁止跨笔记拼接粉丝与发布时间；
7. 搜索到足以完成决策的有效低粉对标后可以停止；若未找到，应完成合理的关键词变体和 90 天范围检查后，才能报告“当前未找到”。

“未找到”必须说明搜索范围和抓取时间，不能等同于绝对不存在。

## 阿里巴巴/1688 货源页

利润阶段优先使用用户提供的 1688 或阿里巴巴货源链接自动提取：

- 规范化货源 URL、商品名和规格；
- 对应规格的单件拿货价；
- 一件代发是否支持；
- 单件运费或运费规则；
- 最低起订量；
- 抓取时间。

先核对货源与小红书商品是同款或可接受替代品。阶梯价必须选择符合“一件代发”和实际采购数量的档位，不得把大批量最低价当作单件价。运费若依地区变化，应请用户确认收货地区或使用页面明确的默认地区；不能确认时不计算正式利润。

如果用户还没提供货源链接，先请其发送一个候选 1688/阿里巴巴链接；除非当前 WorkBuddy 已启用可靠的阿里巴巴站内搜索能力，否则不要声称已经自动找到供应商。

## 素材源

使用已抓取的同款笔记、商品主图/视频及其他可访问平台证据判断素材执行难度。输出证据数量和来源类型，再给 A/B/C：

- A：多来源存在足够图片/视频和可参考内容，前期不依赖实拍；
- B：素材有限但可通过混剪、AI 生图或二创完成测试；
- C：可靠素材不足或主要依赖真人实拍/复杂搭景。

只判断“素材是否可用于前期执行”，不自动断言版权可用。证据不足时标记 `unverified` 并追问，不凭商品类型猜测。

## 证据记录

每个自动字段至少记录：

```json
{
  "value": 468,
  "source_url": "https://...",
  "captured_at": "ISO-8601 time",
  "status": "verified"
}
```

送入评分脚本时使用 `value`；报告中用简短来源说明，不暴露内部工具调用细节。若同一字段出现冲突，优先采用同一商品/规格下更新、更直接的页面证据，并说明冲突。

## 失败降级

自动读取失败时区分：工具未安装、未启用、未授权/未登录、页面失效、风控验证码、字段未展示、证据冲突。最多进行有限的安全只读重试；仍失败就说明具体缺口，每次只向用户询问一个当前字段，不要让用户一次性手工填写全部数据。
